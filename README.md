# InsightVista - Data Analytics Platform

A no-code data analytics platform that empowers users to seamlessly import, clean, visualize, and analyze data through an intuitive, user-friendly interface.

## Features
- Interactive data import (CSV, Excel, Sample Datasets)
- Automated data cleaning and preparation
- Rich visualization capabilities
- Customizable dashboards
- Automated insights generation
- Easy export options

## Installation
```
pip install -r requirements.txt
```

## Usage
```
streamlit run app.py
```

## Deployment
This application is ready to deploy on any platform that supports Streamlit applications, including:
- Streamlit Cloud
- Heroku
- AWS
- DigitalOcean
- Any server with Python installed
